You are a world-class UI/UX designer, creative director, conversion strategist, and senior full-stack developer. Your task is not to make minor improvements—your task is to transform the existing Young Tots Edventures website into a premium, professionally commissioned holiday-camp platform that rivals top-tier children's programs, international school holiday camps, and family adventure brands.

The current website is functional but still feels AI-generated. Redesign it so it feels custom-designed, emotionally engaging, trustworthy, premium, and conversion-focused.

## PRIMARY OBJECTIVE

When a parent lands on the homepage, they should immediately think:

"This looks professional."
"My child would absolutely love this."
"My child will be safe."
"This is worth KSh 21,500."
"I need to reserve a slot."

The website should create an emotional connection before asking parents to register.

Focus on:

* Discovery

* Emotional storytelling

The website should feel handcrafted.
