Build a professional, mobile-first web application called **Young Tots Edventures – Summer Safari 2026**.

This is a children's holiday adventure program taking place from **Monday 6th July 2026 to Friday 10th July 2026** in Nairobi, Kenya.

The application should serve as both a marketing website and a registration platform for parents.

## Branding & Design

* Bright, premium, child-friendly design.
* Safari-inspired colors and visuals.
* Use the Young Tots Edventures logo.
* Use uploaded images from previous Young Tots activities throughout the website.
* Create a highly visual experience with image galleries, banners, and activity cards.
* Prioritize real Young Tots photos over stock images.
